Design your logic model

Press ] or [ to select the next or previous box or arrow. Arrow keys move the selection, Shift with an arrow key moves it further. Enter edits its text. Delete removes it. Escape clears the selection, and the Properties panel then shows the diagram settings. To connect two boxes, press A, select the first box and press Enter, then select the second and press Enter. Tab moves on to the zoom controls and the Properties panel.
